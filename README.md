One line, at most 200 characters, that makes a meeting-that-should-have-been-an-email funny — an entry for [The Meeting That Should Have Been an Email](https://make.fun/bounty/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9) on make.fun.

## The entry

> Somewhere, an email is in therapy because we turned it into a meeting.

## How to run

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` (validating the 1–200 character gate first). The line is 70 characters long.

## Why this angle

Most entries complain about the meeting's length or the wasted hour. This one flips the victim: the email is the one suffering, now in therapy — a fresh turn that lands on its own with no setup, and every word earns its place.
